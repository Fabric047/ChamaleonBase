# 🦎 ChameleonBase

Un convertidor universal y bidireccional diseñado para transformar datos al instante entre múltiples sistemas de numeración y codificación. 

Como un camaleón, tus datos cambian de forma sin perder su esencia.

## 🚀 Formatos soportados
Convierte desde y hacia cualquiera de estos formatos:
* **Binario** (Base 2)
* **Octal** (Base 8)
* **Hexadecimal** (Base 16)
* **ASCII** (Texto plano)
* **Base64**
